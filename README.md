# Pretrain LLM на корпусах русской литературы

## Описание проекта
Данный проект посвящён обучению небольшой языковой модели (~150 млн параметров) на корпусе произведений русской литературы XIX–XX веков. Основная цель — научить модель правдоподобно продолжать заданные фрагменты текста.


## Датасет
В основе проекта лежит датасет `RussianNovels` (около 100 текстов): ```https://github.com/JoannaBy/RussianNovels/tree/master```
- **Формат:** `.txt` файлы, кодировка `UTF-8` (без BOM).
- **Состав:** Тексты преимущественно XIX–XX веков, авторы разного пола и жанровой принадлежности.


## Задача
Научить `decoder-only` трансформер с контекстным окном 512 токенов генерировать связные и стилистически уместные продолжения для заданных фрагментов классических произведений.

## Конфигурация модели
```python
from transformers import LlamaConfig

model_config = LlamaConfig(
    hidden_size=1024,
    intermediate_size=1536,
    num_hidden_layers=16,
    num_attention_heads=16,
    num_key_value_heads=8,  # Grouped-Query Attention
    vocab_size=3000,        # Размер кастомного токенизатора
    max_position_embeddings=512
)
```

## Как запустить
1. Склонируйте репозиторий. 
2. Скачайте датасет. Убедитесь, что тексты находятся в папке `data/`.
3. Установите зависимости из requirements.txt.
4. Откройте Jupyter Notebook `training.ipynb`.
