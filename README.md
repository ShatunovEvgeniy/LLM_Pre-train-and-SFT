# Pretrain LLM на корпусах русской литературы

## Описание проекта
Данный проект посвящён обучению небольшой языковой модели (~150 млн параметров) на корпусе произведений русской литературы XIX–XX веков. Основная цель — научить модель правдоподобно продолжать заданные фрагменты текста.


## Датасет
В основе проекта лежит датасет `RussianNovels` (около 100 текстов): ```https://github.com/JoannaBy/RussianNovels/tree/master```
- **Формат:** `.txt` файлы, кодировка `UTF-8` (без BOM).
- **Состав:** Тексты преимущественно XIX–XX веков, авторы разного пола и жанровой принадлежности.


## Задача
Научить `decoder-only` трансформер с контекстным окном 512 токенов генерировать связные и стилистически уместные продолжения для заданных фрагментов классических произведений.

## Конфигурация модели
```python
from transformers import LlamaConfig

model_config = LlamaConfig(
    hidden_size=1024,
    intermediate_size=1536,
    num_hidden_layers=16,
    num_attention_heads=16,
    num_key_value_heads=8,  # Grouped-Query Attention
    vocab_size=3000,        # Размер кастомного токенизатора
    max_position_embeddings=512
)
```

## Как запустить
1. Склонируйте репозиторий. 
2. Скачайте датасет. Убедитесь, что тексты находятся в папке `data/`.
3. Установите зависимости из requirements.txt.
4. Откройте Jupyter Notebook `training.ipynb`.


# SFT Qwen2.5-0.5B на русскоязычных инструкциях

## Описание проекта
Данный проект посвящён дообучению (Supervised Fine-Tuning) небольшой языковой модели Qwen2.5-0.5B на корпусе русскоязычных инструктивных данных. Основная цель — научить модель корректно форматировать и генерировать связные ответы на пользовательские запросы на русском языке, следуя диалоговому формату `system → user → assistant`.

## Датасет
В основе проекта лежит датасет **alpaca-cleaned-ru** (`d0rj/alpaca-cleaned-ru` на Hugging Face):

- **Источник**: Перевод и адаптация инструктивного датасета Alpaca для русского языка.
- **Формат**: Табличные данные с полями `instruction`, `input` (опционально), `output`.
- **Объём**: ~52 000 примеров инструкций и ответов.
- **Состав**: Разнообразные запросы — от фактологических вопросов и творческих заданий до инструкций по программированию и бытовых советов.
- **Предобработка**: Удалены пустые записи, дубликаты и примеры с некорректной кодировкой.

## Задача
Научить decoder-only трансформер:
1. Понимать структуру диалога в формате чат-темплейта.
2. Генерировать ответы **на русском языке**, сохраняя стиль и тональность ассистента.
3. Игнорировать в функции потерь токены промпта (system + user), обучаясь только на токенах ответа (assistant).
4. Сохранять фактологическую согласованность в пределах возможностей модели 0.5B параметров.

## Как запустить
1. Склонируйте репозиторий. 
2. Установите зависимости из requirements.txt.
3. Откройте Jupyter Notebook `training.ipynb`.
